# Chromosome Phaser Studio

**See which parent each piece of your DNA came from.**

An unphased kit tells you what your two copies of a chromosome look like mixed together. Phasing separates them: this segment from your mother, that one from your father. Chromosome Phaser Studio phases raw kits using Mendelian logic, the inheritance rules themselves, so painted chromosomes and segment work downstream rest on separated parental copies instead of a blend.

**Use it live: [phaser.writteninthegenome.blog](https://phaser.writteninthegenome.blog)**

## What it does

- **Mendelian phasing**: where a parent's or relative's kit makes a child's assignment provable, the phase is set by inheritance, not by statistical guessing
- **Chromosome painting on phased copies**: ancestry shown per parental side, so a segment's origin story includes which line it came down
- **A foundation for matching**: phased data sharpens segment comparison and family reconstruction everywhere else in the suite

Phaser Studio is in active development. The phasing engine is being rebuilt around full Mendelian assignment, and this page tracks the public state of the project.

## Privacy, same rule as everything I build

All processing runs in your browser, on your device. Raw files are never uploaded or stored on a server.
